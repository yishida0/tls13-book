# 作って学ぶTLS 1.3

TLS（Transport Layer Security）は、暗号技術を用いて通信の機密性・完全性・認証を実現するプロトコルであり、現代のインターネットを支える基盤技術の1つです。
Webサイトの閲覧、オンラインバンキング、メールの送受信など、インターネットを介したさまざまなやり取りを安心して行える背景には、TLSによる通信の保護があります。

一方で、TLSが内部でどのように動作しているのかを詳しく知る機会は多くありません。
また、TLSの動作を理解するには、暗号技術だけでなく、ネットワークプロトコルや通信の仕組みなど、複数の分野にまたがる知識が必要です。
そのため、TLSがどのような仕組みで通信を守っているのか、通信のどこまでがTLSで守られているのかを把握するのは容易ではありません。

それでもTLSの仕組みを理解しておくことは安全なシステムを構築・運用するうえで重要であり、暗号技術やネットワーク、セキュリティの知識を深めることにもつながります。

そこで本書では、TLS 1.3クライアントをGo言語でゼロから実装しながら、TLSの構造や処理の流れ、それらを支える要素技術を学びます。
実装を通じて、TLSが通信を保護する仕組みをプロトコルの内部動作のレベルから理解することを目指します。

## 注意事項

- TLSクライアントのみを実装します。
- 暗号プリミティブは、Goの標準パッケージを利用して補います。
- Goの基本的な文法は習得している前提で進めます。
- 学習用の実装のため、エラーを`panic`で落とすなど、実運用のコードでは使わない書き方をしている箇所があります。
- 本書のクライアントでは起こり得ない条件の検査は省いています。受け取ったデータの検査は省いていません。
- テストの網羅性は扱わず、実際のサーバーに接続して動作を確認します。
- 例ではexample.comに接続しますが、TLS 1.3に対応したサイトであれば任意のホストに置き換えられます。
