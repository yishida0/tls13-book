# 次に学ぶこと

完走お疲れさまでした。これにて本書での学習は終了です。
実装したコードは全部で1,000行程度ですが、各要素技術を学びながら実装を進めるのは、なかなか大変だったのではないでしょうか。

本書で学んだ内容をさらに深める題材として、次のようなものがあります。

- サーバー側を実装し、本書で作成したクライアントと通信させる
- 本書ではGoの標準パッケージを利用したX25519やChaCha20などの暗号アルゴリズムを自分で実装する
- TLSに耐量子暗号を導入することで、鍵交換やデジタル署名の仕組みがどのように変わるのかを調べる
- サーバーだけでなく、クライアントも証明書で認証する相互TLS（mTLS）を試す

本書で実装したのはTLS 1.3の機能の一部ですが、仕様を読み、実際にコードを書いて動かした経験は、ほかの技術を学ぶ際にも役立つはずです。
本書が、TLSや暗号技術への理解を深めるとともに、普段何気なく使っている技術の仕組みを自分で調べたり、実装したりするきっかけになれば幸いです。
